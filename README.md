# Kamal Hotel Kathmandu · Web Platform & PMS

A luxury 3-star boutique hotel platform and property management system (PMS) for **Kamal Hotel** located in **Kamalpokhari, Kathmandu, Nepal** (near City Center and historic Kamalpokhari Pond, 15 mins from Tribhuvan International Airport).

Built with React 19, TypeScript, Tailwind CSS, Supabase PostgreSQL, and modern hotel operations workflows.

---

## 🌟 Key Features

### 1. In-House Guest Digital Portal & Dynamic PIN System
- **Keyless Digital Stay Portal**: Checked-in guests log in using their **Room Number** (e.g. `Room 302`) and a dynamic **4-Digit Passcode** (e.g. `4829`) generated by the Front Desk upon arrival.
- **Strict Stay Validation**: The passcode operates strictly during the guest's booked stay dates; expired passcodes cannot access the room.
- **Zero-Trace Data Purge on Checkout**: When the receptionist checks out a room, the PIN is expired, ongoing chat logs are wiped, and room sessions are purged for the next arriving guest.
- **Live Room Statement & Folio**: Guests view real-time balance due, accommodation charges, and live ongoing rooftop dining orders.
- **In-Room Intercom & Two-Way VoIP**: Direct communication between guest and receptionist/waiter with service categorization (*Concierge, Room Service, Housekeeping, Front Desk*).

### 2. Role-Based Access Control (RBAC) & Dedicated Dashboards
Strict departmental boundaries enforced across all operations:
- **Super Admin (`superadmin` / `KamalHotel@2026`)**: Full ownership, CMS content customizer, theme & rate adjustments, staff roster & credential management, Supabase database synchronization, and security audit logs.
- **Hotel Manager (`manager` / `Manager@2026`)**: Operational reservations, room inventory, P&L financial accounting (Daily, Weekly, Monthly, Quarterly, Yearly), and billing folios.
- **Receptionist / Front Desk (`receptionist` / `Reception@2026`)**: Express guest check-in/out, live room availability matrix, issuing dynamic guest stay passcodes, and master billing prints.
- **Head Chef (`chef` / `Chef@2026`)**: Kitchen ticket board (`placed` $\rightarrow$ `preparing` $\rightarrow$ `ready_for_delivery`), menu pricing, recipe specials, and dietary flags (*Veg, Spicy, Chef Special*).
- **Service Staff / Waiter (`waiter` / `Waiter@2026`)**: Table service and room service deliveries, in-room ticket dispatch, and guest dining preferences.
- **Housekeeping (`housekeeping` / `Clean@2026`)**: Room turnover tracking, inspection logs, and linen/toiletries inventory.

### 3. Master Invoicing & 5 Printable Bill Templates
- **Automated Tax & Surcharge Computation**: Automatic calculation of **13% Nepal VAT**, **10% Hotel Service Charge**, and custom discounts.
- **5 Selectable & Fully Customizable Print Designs**:
  1. **Heritage Gold**: Regal maroon and gold frame with authentic Newari borders and dual QR payment box.
  2. **Executive Modern**: Clean corporate typography with detailed service categorization.
  3. **Minimalist Clean**: Understated boutique elegance with airy whitespace.
  4. **Regal Himalayan**: Rich mountain sapphire and burgundy accents ideal for suite luxury folios.
  5. **Compact POS Thermal**: 80mm format for thermal receipt printers and express front desk checkouts.
- **Bill Customizer Settings**: Edit hotel logo URL, PAN/VAT registration number, legal name, footer notes, and authorized signatory.

### 4. Stock & Inventory Management
- Categorized across 6 hotel departments (*Kitchen Ingredients, Beverages & Bar, Housekeeping & Toiletries, Linen & Bedding, Maintenance & Solar, Front Office Stationery*).
- Instant filters for **Low Stock Alert** (items below minimum threshold) and **Out of Stock** (immediate reorder required).
- Quick stock adjustments (`+ Add Stock In` / `- Consume Out`) with reason logging.

### 5. Multi-Currency Engine
- Live conversion and rate display in **Nepali Rupees (रू NPR)**, **US Dollars ($ USD)**, and **Indian Rupees (₹ INR)**.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm or pnpm

### Installation
```bash
git clone https://github.com/your-username/kamal-hotel-kathmandu.git
cd kamal-hotel-kathmandu
npm install
```

### Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Fill in your Supabase credentials:
```env
VITE_SUPABASE_URL="https://your-project.supabase.co"
VITE_SUPABASE_ANON_KEY="sb_publishable_your_key_here"
```

### Running Locally
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### Building for Production
```bash
npm run build
```
The output directory will be `dist/`, ready to deploy to **GitHub Pages**, **Vercel**, **Cloudflare Pages**, or **Netlify**.

---

## 📦 Deployment to GitHub Pages

1. In `vite.config.ts`, if deploying to a subpath like `https://username.github.io/repo-name/`, set `base: '/repo-name/'`.
2. Add the `gh-pages` script or use GitHub Actions:
```bash
npm run build
```
Deploy the `dist/` folder to the `gh-pages` branch.
